### ⚠️ 发现并修复的一个隐藏大坑
pip 源原本被配成清华镜像，但对 FireRed 需要的那批新版本包（torch / funasr / faiss 等），清华源返回空列表（`from versions: none`），会导致安装全部失败。
已把两个环境（生产 + 沙盒）的 pip 源都改成**官方源 pypi.org**，实测 torch 2.15 / torchaudio 2.11 / funasr / transnetv2 / faiss-cpu / av / sentence-transformers / librosa / moviepy / skillkit / mcp 全部有 Python 3.13 可用的 wheel。**这个坑不提前发现，真正安装时必然报错。**
