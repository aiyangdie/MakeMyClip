# MakeMyClip

> 把淘宝商品视频/图片拖进来，自动识别画面、按卖点选片、配上中文字幕与配音，导出一条可直接上传的主图视频。

一个本地运行、原素材只读、分阶段构建的商品主图视频自动生成工具。使用该工具不需要懂剪辑，也不需要把商品视频上传到任何服务器。

---

## 一、它能做什么

| 环节 | 说明 |
| --- | --- |
| 项目管理 | 新建/打开项目，数据存成独立的 `.db` 文件，关掉再开数据都在 |
| 素材导入 | 拖入视频文件或整个文件夹，自动读取时长、分辨率、帧率、编码、音轨 |
| 素材安全 | **原始视频全程只读**；中文路径用硬链接代理播放，不改原件、不改名、不删除 |
| 拆镜分析 | 按画面真实变化把长视频拆成候选镜头，而非按文件大小或等时间间隔硬切 |
| AI 识别评分 | 本地视觉分析 + 六维质量评分（清晰度/曝光/稳定性/构图/干净度/无遮挡），每条结论带证据和置信度 |
| 自动选片 | 按分镜模板（如床头柜 12 镜）为每个镜头挑最佳候选，内容准确性优先于画质 |
| 时间线编辑 | 逐镜头改起止、建议时长、替换候选、锁定、排序；**改一个镜头不影响其他镜头**（独立缓存 + 增量重渲染） |
| 字幕与音频 | 中文字幕、本机 Windows 中文语音离线配音、无版权背景音乐（旁白出现时自动压低音乐） |
| 一键出片 | 3:4 竖版（淘宝商详页推荐）等比例适配，不拉伸商品；文件名带时间戳，绝不覆盖旧片 |
| 智能体剪辑 | 通过 MCP 接口让 AI 智能体替你操作软件，操作全程记日志、可审计 |

**三条焊死在代码里的安全护栏：** 原素材只读 · 锁定的镜头智能体也改不动 · 导出成片必须先经你确认。

## 二、原理：一条视频是怎么被"自动剪"出来的

```
素材导入 ──► 拆镜检测 ──► 视觉识别+评分 ──► 分镜匹配 ──► 时间线 ──► 字幕/配音/BGM ──► 导出 MP4
 只读原片     找真实切点      找卖点、打分       挑最佳镜头     逐镜头编辑      三轨合成          3:4 竖版
```

- **拆镜**：检测画面信号的真实变化，得到候选镜头；灯光/色温变化会被标记为"低置信度、需人工核验"，不冒充确定切点。
- **识别评分**：默认用图像信号启发式（不联网、不上传），报告"观察到几种灯光状态""有无往复运动"等可测事实；语义结论一律标"需人工核验"，置信度上限压到 0.75，不假装是深度学习识别。
- **选片**：内容准确性优先于画质，找不到合适素材就如实标"缺失 + 补拍建议"，不拿别的镜头硬凑。
- **导出**：每个镜头独立缓存，改一处只重渲染那一处；等比缩放 + 补边，商品不变形。

> 项目还有一个独立的沙盒验证目录 `ai_fusion_sandbox/`，用本地视觉大模型做过"逐帧识别 → 按内容切镜头 → 配音配乐成片"的端到端实验，详见该目录内报告。这部分是验证成果，未接入生产代码。

## 三、技术栈

| 层 | 技术 |
| --- | --- |
| 界面 | Python + PySide6（桌面 GUI），QThread 后台任务不卡界面 |
| 视频处理 | OpenCV（逐帧读取/拆镜）、imageio-ffmpeg（自带 ffmpeg，剪辑与编码） |
| 数值计算 | NumPy |
| 数据库 | SQLite（项目/素材/分镜/候选/任务全本地存储） |
| 图像 | Pillow |
| 配音 | Windows SAPI 本机中文语音（离线、免费、不上传），接口可替换 |
| 音乐 | 程序本地合成的无版权音垫，无需外部音频 |
| 智能体 | FastMCP（MCP 工具接口），操作审计写本地日志 |

完整依赖见 `requirements.txt`。**没有云端依赖，不联网也能出片。**

## 四、安装与运行

```bash
# 1. 安装依赖（Windows 双击 安装依赖.bat，或手动：）
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2. 启动（Windows 双击 一键启动.bat，或手动：）
python main_wizard.py      # 五步向导界面（推荐，新手用这个）
python main.py             # 完整工作台（八页，功能全）
```

首次使用建议走五步向导：`导入素材 → 挑镜头 → 看片调整 → 字幕配音 → 一键出片`；需要精细控制时从向导右上角进入完整工作台。

## 六、项目原则

1. **原素材只读** —— 导入、播放、抽帧、导出全程不修改原始文件。
2. **先核验再认定** —— 画面证据不足时如实标注"需人工核验"，绝不编造卖点或商品参数。
3. **非破坏性编辑** —— 每个镜头独立缓存，改一个镜头不影响其他已确认镜头；锁定镜头默认拒绝修改。
4. **先确认再导出** —— 智能体导出成片前必须向用户说明并取得同意，每步操作可审计。
5. **只增不改** —— 每次升级保留历史文档与成片，新增内容带版本标记，随时可回退。

## 七、版本与测试

- 版本基线：`v2.0-baseline-before-ai-fusion`（AI 融合前的稳定快照）。
- 测试：各阶段 `tests/test_stage*.py`，累计 200+ 项；阶段报告记录每次验收结果。
- 已知边界：本地识别是图像信号启发式而非深度学习语义识别；配音是本机机械女声；材质/承重/认证等未经核实的词默认禁止写入文案。

详见 `使用说明.md`（按 v1→v13 累积）与各 `阶段*报告.md`。
